# Sales Performance & Customer Segmentation Analytics

## Project Overview

A Power BI-based business analytics project developed to analyze sales performance, customer behavior, KPIs, and customer segments using transactional sales data.

## Objectives

- Analyze sales and profit performance
- Track key business KPIs
- Identify regional and category-level performance
- Analyze customer purchasing behavior
- Segment customers using RFM analysis and K-Means clustering
- Build interactive Power BI dashboards

## Data Processing

Python and Pandas were used for data cleaning, preprocessing, RFM analysis, and customer segmentation.

Power Query was used in Power BI for data transformation and validation.

## Power BI Implementation

- Power Query transformations
- Data modeling
- DAX measures
- KPI development
- Interactive dashboards
- Sales trend analysis
- Regional and category analysis
- Customer segmentation analysis

## Key KPIs

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Profit Margin
- Average Order Value

## Customer Segmentation

Customers were analyzed using:

- Recency
- Frequency
- Monetary Value
- RFM Analysis
- K-Means Clustering
